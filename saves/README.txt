Supported Versions:
Minecraft:               1.21.1
Cobblemon:  		 1.7.1

This map requires the Cobblemon mod:
Official Website: https://cobblemon.com/en
Mod Download (Curseforge): https://www.curseforge.com/minecraft/mc-mods/cobblemon/files/all?page=1&pageSize=20&version=1.21.1
Fabric is recommended for this map. Fabric needs the following dependency:
    https://www.curseforge.com/minecraft/mc-mods/fabric-api



SINGLEPLAYER
This map, the folder titled "Johto" within this zip file, simply goes into your *saves* folder in whichever launcher you are using to run Cobblemon! Right click and copy the folder from this file, and paste it into your saves folder. Click the world within Minecraft to load in. 


Cobblemon's guide on installing the mod:
https://wiki.cobblemon.com/index.php/Guides/Installation

Use a third-party launcher like Curseforge/Modrinth to quickly auto install the required mods

Curseforge Launcher:
https://www.curseforge.com/minecraft/modpacks/cobblemon-fabric/files/7256433

Modrinth:
https://modrinth.com/modpack/cobblemon-fabric/version/1.7.1





MULTIPLAYER
If you'd like to run the map on a server you can copy and paste the world file "Johto" and the server.properties file to hopefully automatically configure which settings your server will need to run the map. Primarily you'll need the two settings "level-name=Johto" and "enable-command-block=true", but feel free to use the included file to troubleshoot if settings don't seem right on your server. The provided server.properties file also includes a prompt for the resource pack to your players!


Resources for creating a Fabric server on Windows:
https://wiki.fabricmc.net/player:tutorials:server:windows

Fabric Loader 0.17.3 recommended!



OPTIONAL
Download the Music Pack from http://cobblemonjohto.jond.tv and copy the resource pack to your .minecraft/resourcepacks folder (or corresponding modpack resourcepack folder on other launchers). You will then need to enable the pack in Minecraft and you should hear tunes from the radio. Turn off the Music category in your settings for no overlap with any vanilla music.
